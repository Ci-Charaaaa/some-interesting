# Some Interesting 模组功能说明文档（1.21.1 重构基准）

> 本文档是 **1.21.1 全面重构** 的功能与内容基准。
> 目标：**功能上与原 26.x 版本完全一致**，底层技术允许（且鼓励）大幅重写。
> 因此：技术层面只列要点供参考；**功能、内容、数值、交互、文案全部列出**，作为重构的验收依据。
>
> 用途：开发时对照本清单逐项实现；完成后再逐项验收。

---

## 0. 重构技术要点（简）

仅列出当前实现的关键技术点，供重构时参考，**不限定新实现方式**：

- 熟练度数据用 **物品数据组件**（`DataComponentType`，record 实现 `TooltipProvider`）随物品保存，16 种装备各一个组件。
- 熟练度由 **Fabric 事件回调 + 服务端 Tick 检测 + 少量 Mixin** 驱动增长。
- 升锻台用 **方块实体 + Container Menu**（硬编码配方表）。
- 灵魂绑定用 **世界级 NBT 文件** 持久化（`ItemStack.CODEC` + `RegistryOps`），非 SavedData。
- 网络用 Fabric 网络 API，共 **4 个 `CustomPacketPayload`**。
- 配置用 Gson 读写 + Cloth Config 界面 + ModMenu 集成。

## 2. 武器熟练度系统（核心系统）

### 2.1 通用概念

- 共 **16 种装备** 各自有独立熟练度，数据随物品保存。
- 成长阶段（4 级，逐步解锁）：

| 阶段 | 状态名 | Tooltip 颜色 |
|------|--------|--------------|
| 1 | 初识（familiarizing） | 深灰 |
| 2 | 粗通（adept） | 绿 |
| 3 | 默契/精通（synchronized） | 蓝 |
| 4 | 灵魂相通（soulbound） | 金 |

- **达到阈值即自动升级**（无需操作）。
- **升级通用效果**（每种装备都执行）：
  1. 播放玩家升级音效（`PLAYER_LEVELUP`）。
  2. 发送多条聊天消息：等级提示（含物品名）、附魔修复惩罚已重置、耐久上限提升百分比（并显示当前耐久值）、对应加成项。
  3. `MAX_DAMAGE` 变为 原值 × 耐久倍率。
  4. `REPAIR_COST` 重置为 0。
  5. 重建物品属性修饰：**移除本模组旧修饰符，保留物品原有其他修饰符**，再写入新加成。
  6. 授予对应进度（粗通/精通/灵魂相通）。
- **暴击判定**（剑/锤/斧使用）：下落高度 >0、未落地、不在水中、无失明效果、未骑乘。

### 2.3 各装备细节

**镐 — 稀有计数**：挖掘钻石矿/绿宝石矿/下界合金残骸（`c:diamond_ores`、`c:emerald_ores`、`c:netherite_scrap_ores`）时「稀有」计数 +1，普通方块只加普通计数。

**锄 — 双触发**：挖掘 `mineable/hoe` 方块、或右键泥土/草方块/菌丝土/粗泥/缠根泥土耕地，均触发。

**盾牌**：左手或右手举盾均可；以盾牌耐久（DAMAGE 组件）增加为判定。

**护甲**：任意部位受损即给该部位 +1，每 tick 检测一次血量下降。

**鞘翅**：滑翔中每累计 20 tick（1 秒）计数 +1；速度加成作用于滑翔移动速度。

**打火石**：右键点燃苦力怕（苦力怕引爆）会标记「已点燃苦力怕」；开启配置「灵魂相通需点燃苦力怕」时（默认开），不标记无法升至灵魂相通。升级到精通时若未标记，额外提示「点燃一只苦力怕以完成最大的使命」。

### 2.4 Tooltip 显示（所有装备通用规则）

按当前阶段显示：
- 阶段名（对应颜色）。
- 计数行：「攻击/挖掘/……默契度：当前值 / 目标值」（最高阶段显示 `MAX`）。
- 各装备附加显示对应加成（如弓/弩显示箭矢倍率，鞘翅显示速度加成，钓竿显示效率与宝藏）。

## 3. 灵魂绑定系统

### 3.1 绑定流程（绑定粉）

条件（主手=绑定粉，副手=物品）：
1. 副手为空 → 失败提示「副手没有物品！」。
2. 副手已有灵魂绑定标记 → 失败提示「该物品已被灵魂绑定，无法再次绑定！」。
3. 副手未达到「灵魂相通」阶段 → 失败提示「副手物品尚未达到灵魂相通！」。

成功流程：
1. 给副手物品写入标记：`soul_bound`（布尔）、`bind_time`（毫秒时间戳）。
2. 将物品**副本**存入玩家绑定列表。
3. 主手绑定粉消耗 1 个。
4. 播放铁砧/附魔音效（`ENCHANTMENT_TABLE_USE`）。
5. 发送成功消息（含物品名）+ 提示「若该物品无合成配方，绑定仅作装饰/纪念用途」。
6. 同步绑定列表到客户端。
7. 授予进度「proficiency/bound」。

### 3.2 持久化存储

- 文件位置：`<世界>/data/some_interesting_bound_items.nbt`。
- 内容：
  - `玩家标识 → 绑定物品列表`（物品用完整 `ItemStack` 编码，含熟练度组件/附魔/名称）。
  - 冷却表：`玩家标识 → (物品索引 → 上次合成时间戳)`。
- 玩家标识策略：正版在线模式用 **UUID**，离线模式用 **玩家名**。
- 生命周期：服务端启动加载 → 每次存档前保存 → 服务端停止保存 → 服务端停止后清空内存。

### 3.3 绑定界面（K 键打开）

**布局（340×230）**：
- 标题「灵魂绑定」；副标题「合成」。
- 左侧面板（宽约 170）：绑定物品列表，**每屏 4 行，行高 28**，可滚动。
  - 每行显示：物品图标、名称、绑定时间（格式 `yyyy-MM-dd HH:mm:ss`）。
  - 收藏物品置顶，行首显示金色 ★。
  - 选中项金色高亮边框。
- 右侧：3×3 合成格 + 1 结果格（带箭头装饰）。
- 底部：玩家背包 3×9 + 快捷栏 1×9。
- 无绑定物品时显示「暂无绑定物品」。

**交互**：
- **左键点击**列表物品 → 选中并通知服务端（选择该物品用于合成）。
- **右键点击**列表物品 → 切换收藏（通知服务端，重新同步）。
- **滚轮**在左侧面板滚动列表。
- **K 键**关闭界面。
- 点击冷却中的物品 → 提示「合成冷却中，剩余 X 小时 Y 分钟」。

**首次打开提示**（每个会话每玩家一次，通过聊天发送 7 行说明）：绑定方法、选择、收藏、合成、产物、备注。

### 3.4 合成规则（灵魂绑定合成）

- 选择左侧物品后，在右侧 3×3 放入材料。
- 使用**原版合成配方表**匹配：若某原版配方产物与选中物品是同一物品，则结果 = **选中物品的满耐久全新副本**（耐久归零、保留熟练度组件/附魔/名称等一切组件）。
- 冷却中不产出结果。
- **取出结果 → 该物品进入 24 小时冷却**（必须先设冷却再交付产物，防止快速点击绕过）。
- 无对应原版配方的物品（如三叉戟、鞘翅）绑定后仅作收藏/纪念，不可合成。

### 3.5 网络同步

- 加入服务器时、绑定成功后、收藏切换后，服务端向客户端推送绑定列表。
- 客户端缓存列表用于界面展示。

## 4. 升锻台系统

### 4.1 界面（176×166，使用原版工作台贴图）

- 工具槽：x8, y34（放置要升级的工具/装备）。
- 材料 3×3：起点 x30, y17（共 9 格）。
- 结果槽：x124, y35。
- 背包 3×9：x8, y84；快捷栏：y142。

### 4.2 方块实体槽位（共 11 格）

0~8：材料 3×3；9：工具槽；10：结果槽。

### 4.3 升级配方规则（硬编码，非数据包）

- 指定材料槽位必须放对应材料，**其余槽位必须为空**。
- 工具槽物品满足来源条件 + 材料满足 → 结果=目标物品。

### 4.4 工具类配方（材料位置）

| 工具 | 材料占用格子（3×3） |
|------|---------------------|
| 剑 | {1, 4} |
| 镐 | {0, 1, 2} |
| 斧 | {0, 1, 3} |
| 铲 | {1} |
| 锄 | {0, 1} |
| 长矛 | {2}（⚠ 1.21.1 删除，见 §7） |

**工具升级链**（每个工具独立）：

```
木 → 石(用圆石) → 金(金锭)/铜(铜锭)/铁(铁锭) → 金→铜 → 铜→铁 → 铁→钻石 → 钻石→下界合金
```

### 4.5 盔甲类配方（材料位置）

| 部位 | 材料占用格子 |
|------|--------------|
| 头盔 | {0,1,2,3,5} 或下半部 {3,4,5,6,8} |
| 胸甲 | {0,2,3,4,5,6,7,8} |
| 护腿 | {0,1,2,3,5,6,8} |
| 靴子 | {0,2,3,5} 或 {3,5,6,8} |

**盔甲升级链**：

```
皮革 → 金/铜/铁 → 金→铜 → 铜→铁 → 铁→钻石 → 钻石→下界合金
```

### 4.6 产物规则（重要行为契约）

- 产物为**目标物品**，**保留工具原有一切非默认组件**：
  - 保留：附魔、自定义名称（非默认名）、熟练度组件等。
  - 排除：`DAMAGE`、`MAX_DAMAGE`、`ATTRIBUTE_MODIFIERS`、`TOOL`、`ITEM_MODEL`、默认 `ITEM_NAME`。
- 取出结果时消耗：每个占用材料格 -1 + 工具 -1；支持 Shift 快速取走。
